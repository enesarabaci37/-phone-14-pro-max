# arabacireklam.com

Arabacı Reklam (Taşköprü / Kastamonu) web sitesi. Tek sayfa, statik HTML.

- `index.html`: site
- `assets/logo/`: Arabacı Reklam logoları (SVG) ve `arabaci-oto/` altında arabacı oto film alt markası
- `assets/img/`: iş ve atölye fotoğrafları (`-sm` sürümleri 700 px, diğerleri 1400 px; plakalar bulanıklaştırıldı)
